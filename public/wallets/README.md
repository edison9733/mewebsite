# Wallet logos

Drop an SVG here named after the wallet's `logo` value in `src/finance/config.js`:

| File to add        | Wallet(s) that use it |
|--------------------|------------------------|
| `boc.svg`          | BOC (CNY)              |
| `icbc.svg`         | ICBC (CNY and MYR)     |
| `wechat.svg`       | WeChat Pay (CNY)       |
| `alipay.svg`       | Alipay (CNY)           |
| `maybank.svg`      | Maybank (MYR)          |
| `gxbank.svg`       | GXBank (MYR)           |
| `wise.svg`         | Wise (MYR and USD)     |
| `jupiter.svg`      | Jupiter (USD)          |
| `bitget.svg`       | Bitget (USD)           |

Rules:

1. The file must be a real `.svg`. A `.png` renamed to `.svg` will not render.
2. Square-ish artwork looks best; the tile is 30–38px and the logo is padded inside it.
3. Until a file exists, the app shows a coloured monogram instead — nothing breaks.
4. No code change is needed after you add a file. Refresh the page and it appears.

These are third-party trademarks. Use the official logo files from each brand's
own press or brand-assets page, and follow their usage rules.
